# automation/ — generated tests (README-format)

Generated by HydraLabs from Jira (`HydraLabs/testengine/tools/jira/render_pytest.py`). Layout matches the
framework README: `apps/<App>/{data,locators,modules}` and `tests/<App>/`. **Do not hand-edit** the shared
`*_locators.py` / `*_module.py`: they are rebuilt from every case on each run.

This folder holds generated output only. The tests import `utils.*` and `config.settings` from the framework
repo (`infra-it-automatizacion-facturacion-broker`), so to run them, copy `apps/CobroOrdenes/` and
`tests/CobroOrdenes/` into that repo and register the suite in `runner_central.py` (README, "Escalabilidad").

Regenerate:

    python3 HydraLabs/testengine/tools/jira/render_pytest.py --cases HydraLabs/testengine/out/jira \
        --include-review --app CobroOrdenes --out automation

Before trusting a test: selectors marked `TODO` in the locators file are guesses, `BASE_URL` must point at the
portal, and any test that skips lists the steps that still have no rule.
