# Hydra-__APP__

Automated tests for __APP__, generated by HydraPloy/HydraLabs from the app's test cases and reviewed by a person.

```
tests/__APP__/test_*.py          one test per case
apps/__APP__/{data,locators,modules}   its data, selectors and reusable steps
hydra/                           what the pipeline keeps for this app (see hydra/README.md)
```

Run them: `pip install -r requirements.txt && playwright install chromium`, copy `.env.example` to `.env`, then
`pytest tests/__APP__` (add `--html=reports/report.html --self-contained-html` for a report with screens and video).
