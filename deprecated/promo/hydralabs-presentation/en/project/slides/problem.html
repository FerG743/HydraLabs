Humans write the cases. The pipeline does the rest.

1 · Write

QA writes and documents each case in Jira first. That is the human gate.

2 · Automate

The pipeline reads the case, maps its steps to the real app and renders a test.

3 · Prove

The test must pass in the real framework, run three times in a row, before it counts.

A rendered test is not an automated test. Only a passing one is.

The three steps map to the scope sentence. Stress that "rendered" does not count; only a test that passes does.
